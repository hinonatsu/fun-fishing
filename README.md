# FUN FISHING

「一画面でひとつの判断」をしながら、自分に合う釣りと道具を選べる、ログイン不要のWebアプリです。

## 起動と検証

Node.js 22.12以降を使用します。

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

`http://127.0.0.1:5173/fun-fishing/` を開きます。

```sh
npm run typecheck
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

このWindows環境でインストール済みのPlaywrightブラウザを使う場合：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = 'C:\Users\ntksh\AppData\Local\ms-playwright'
npm run test:e2e
```

本番ビルドは `dist/`、Viteのbaseは `/fun-fishing/`。既存の `codex/fishing-hero` ブランチへのPushでGitHub Pagesのデプロイが走ります。

## 操作フロー

1. 開始 → 月 → エリア → 地形。各条件を独立した画面で選択。
2. 診断は一画面一問。楽しみ方・過ごし方・予算の3問で結果を見られます。追加質問は任意で、回答を続けたり、途中から結果を見たりできます。現在は追加9問を用意しています。
3. 魚種 → 釣り方。魚と釣り方は別画面で選択。魚種の並び順・理由に診断回答を反映します。
4. 必要な道具8カテゴリを一覧表示。一覧のカテゴリや「商品を選ぶ」から商品候補の別画面へ進み、選ぶと一覧の該当行へ反映します。選ぶ順番は自由です。全スロットは未選択から始め、おすすめは目印のみ。所持品・リール付属の糸も明示的に選び、全カテゴリがそろってから構成確認へ進みます。
5. 構成を確認 → 購入先確認／保存を選択。価格比較・送料入力は任意の独立画面。Amazon個別リンク、準備チェック、保存URLを利用できます。

選んだ道具に公称仕様が明確に合わない候補は表示しません。未知の仕様は「要確認」に残します。上流の道具を選び直しても、下流の商品を勝手に置き換えません。付属糸を選んだ後にリールを変更した場合は、ラインの再選択へ案内します。

道具一覧と商品選択には、部品ごとに色が変わる全体図を表示します。未選択はグレー、選択済み・手持ち・付属品はカラー。現在選ぶ部分は金色の輪郭と文字で示します。`#rigs/sabiki` またはフッターの「仕掛け図鑑」から12種類の仕掛けを閲覧できます。具体的な商品選びは引き続きサビキ釣りに対応します。図の構成と参照資料は [仕掛けイラスト](docs/RIG_ILLUSTRATIONS.md) を参照してください。

## 価格とデータの範囲

初心者向けの30対象魚（近縁種のグループ・イカ類を含む）と12釣法を選択できます。別名検索・釣法での絞り込み・有名順とおすすめ順に対応。全国一覧と地域別の季節データは区別し、東京湾・堤防のイワシ・小サバは4〜10月、アジは5〜10月の目安を収録しています。購入商品まで案内するのは、この条件の足元のサビキのみです。他の魚・釣法では準備品と始め方を案内し、サビキ商品を流用しません。詳細は [30対象魚の仕様](docs/FISH_CATALOG.md) を参照してください。

14実商品・8カテゴリ。購入先は検証済みAmazon個別商品ページです。全商品の価格をGitHub Actionsで毎朝7:17（日本時間）に取得し、取得日時とともに表示・比較します。手入力の購入単位の税込価格があれば優先します。取得失敗・36時間超の価格は集計せず、品切れと取得失敗を区別します。送料は手入力です。アフィリエイト契約、決済・一括カート連携は未接続です。

価格取得の手動実行・データ形式・失敗時の動作は [Amazon価格更新](docs/AMAZON_PRICES.md) を参照してください。

比較対象は固定のメーカー品中心構成。同じ選択済みカテゴリを比較し、所持品・付属品を両方から除外します。価格未入力を0円として扱わず、必要な金額がそろうまで差額を出しません。送料未入力では商品代の差額と明示し、送料がそろったら支払総額の差額を表示します。汎用バケツは地上で給水する用途に限って比較します。性能全体が同等という主張ではありません。

## 保存と互換性

`localStorage` の `fun-fishing-build-v1` キーに自動保存します。ペイロードはv2へ更新し、旧v1の共有URL・保存データも読み込めます。診断回答、商品選択、所持品、付属品、手入力価格、送料、準備チェックを保存します。

各画面に固有のURLフラグメントがあります。戻る・進むでは同じプランの選択を保ち、直接URLで途中の画面を開いても不足する判断へ案内します。共有URLを知る人は同じリストと回答・価格を復元できます。共有後の変更は各ブラウザで独立します。

共有データは商品ID・カテゴリ・質問と回答・金額・月・魚・釣法を検証します。外部購入先は共有URLから受け取らず、同梱した許可済みHTTPS URLだけを使用します。

## ソース構成

- `src/App.tsx`: 画面遷移・履歴・保存・復元。
- `src/FlowPages.tsx`: 一画面一判断の共通レイアウト、条件選択。
- `src/diagnosis.ts`, `src/DiscoverPage.tsx`: 診断定義、追加質問、魚種と釣法。
- `src/EquipmentPages.tsx`: 必要な道具の一覧、カテゴリ別商品選択、構成確認、価格・送料比較、購入・保存。
- `src/planner.ts`: おすすめ、候補絞り込み、進行条件、価格比較。
- `src/catalog.ts`, `src/domain.ts`: 商品と出典、仕様ルール、共有データの検証。
- `src/*.test.ts`, `tests/`: 単体テスト・PC／モバイルの操作・表示・アクセシビリティ検証。

詳しくは [プロダクト仕様](docs/PRODUCT_SPEC.md)、[出典](docs/DATA_SOURCES.md)、[Amazonリンク](docs/AMAZON_LINKS.md)、[検証記録](docs/QA_REPORT.md) を参照してください。
