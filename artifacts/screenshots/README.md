# 実画面スクリーンショット

`guided-*` は一画面一判断の最新版です。PCの入口・診断・道具選択と、スマホの道具選択を保存しています。最新の全画面・6サイズの画像は `npm run test:e2e` で `test-results/` 以下へ再生成できます。

以下の番号付き画像は、前版のおまかせ構成を使う4ステップの記録です。

2026-10-30、Playwright / Chromiumで取得。魚・道具・港はオリジナルのSVGイラストです。

`desktop-chromium-*` は1440×900、`mobile-chromium-*` は390×844で操作した画面です。スクリーンショットはCSSピクセルで保存。通常画面は全ページ、検索パネル・ダイアログは実際のviewportを撮影しています。

|番号|状態|
|---|---|
|01|トップページ|
|02|月の検索パネルを開いた状態|
|03|検索結果・魚種選択|
|04|釣り方選択・他釣法の説明|
|05|ビルダー初期状態（別途viewport画像あり）|
|06|商品選択パネル|
|07|商品変更後|
|08|非推奨の警告（別途viewport画像あり）|
|09|完成・準備リスト|
|10|構成URLの共有ダイアログ|
|11|未対応条件と代替プラン|

`responsive-幅x高さ-*` は360×800、390×844、768×1024、1280×800、1440×900、1920×1080のトップ・魚選択・ビルダー・リストです。固定バーが全ページ画像の途中に写る場合があります。固定要素の位置はviewport画像と合わせて確認してください。

`review-before-*` は修正前の比較用です。`final-home-viewport.png` は最終のトップページ表示です。

テスト範囲と実行結果は `docs/QA_REPORT.md`、修正内容とレビューは `docs/UX_REVIEW.md` に記録しています。
