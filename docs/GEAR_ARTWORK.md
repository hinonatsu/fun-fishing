# 釣り具イラスト

全25カテゴリの道具を、実物の構造と素材感が分かるイラストとしてSVGで配信する。
金属の反射、カーボンの織り目、コルク、布の縫い目、透明な糸と樹脂、網目を描き分けている。
スナップ・サルカン・針、オモリ・保護ゴム・ウキ取付セットもそれぞれ異なる形状で描画する。
イラストは道具の種類を示すもので、特定の商品の写真ではない。

- 商品選択・構成確認・買い物リストは共通の `GearIllustration` を使用。
- 12釣法の仕掛け図にも竿・リール・カゴ・ウキ・オモリ・サルカン・ルアー・エギ・携行用品の同じ描画を使用。
- ヘチ釣りのリールはタイコリールとして描き分ける。釣法・対象魚ごとの接続や専用仕掛けの区別を維持。
- 未選択はグレー、ホバー中と選択済みは素材の色で表示。図の番号・凡例・クリック・キーボード操作は維持。
- 各SVGはローカルファイルとして配信して再利用し、細かな図形を画面ごとに大量生成しない。

## 編集と再生成

ベクター描画の原本は `scripts/gear-artwork-source.tsx`。
リール・ライフジャケットは、組み込みの `image_gen` で背景透過の商品イラストを生成し、
`public/images/gear/reel.webp`・`reel-drum.webp`・`safety.webp` に保存している。
金属加工、ベールとローター、ナイロン生地、メッシュ、浮力材の厚み、縫い目と留め具を描写する。
各WebPをSVGに埋め込むため、商品カード・仕掛け図の配置と選択状態の表示を共通のまま使える。
生成条件と完全なプロンプトは [素材の生成記録](gear-reel-safety-image-prompts.json) を参照。
以下で `public/images/gear/` の25カテゴリと2つの図解用バリエーションを再生成する。
再生成したSVGもコミットするため、通常のビルド時に生成処理は不要。

```powershell
node scripts/prepare-gear-artwork.mjs
npm run build
npx vitest run src/rigs.test.ts
npx playwright test tests/rigs.spec.ts
```

表示サイズと未選択・ホバー時の見た目は `src/gear-artwork.css`、図中の配置は `src/RigDiagram.tsx` で調整する。
