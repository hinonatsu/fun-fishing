# 互換性ルール

実装: `src/domain.ts` の `evaluateCompatibility(selection, owned)`。商品データ: `src/catalog.ts`。確認日: 2026-10-30。

この関数は入力を変更しません。変更した商品を勝手に消すこともありません。選択品ごとに、その時点の組み合わせを再計算します。

## 判定の意味

|状態|画面表示|意味|
|---|---|---|
|`recommended`|推奨|その項目について公開仕様と記載したルールの条件内。現物使用全体の保証ではありません。|
|`check`|要確認|情報がない、仕様表記外、または現場・利用者の条件次第。|
|`avoid`|非推奨|公開されている負荷等の明確な上限を超える。|

選択済み8点と、仕様ルールの確認件数は別です。購入/準備済みチェックも互換性の認証を意味しません。

## 実装ルール

1. **未選択・所持品:** 商品IDがない/カテゴリが違う場合は要確認。所持品の型番は未登録なので、掲載商品の仕様を流用せず関連する数値判定を止めて要確認にします。所持品の不明な仕様は、実際の判定ルールで依存する相手のカテゴリにも要確認として伝えます。例えば所持ロッドはロッド自身に加えリールの取り付け・カゴとエサの総負荷・仕掛けのハリスへ影響します。リールと糸の容量比較だけが推奨でも、所持ロッドとの取り付けが未確認のリールを推奨とは表示しません。
2. **竿とリール:** スピニング用候補であってもリール脚/固定部の寸法と実物装着は未検証。常に要確認です。
3. **リールとナイロン糸:** メーカーが同一号数で公表する巻糸量と、構成で使う150mを比較。150mが容量以下ならこのルールは推奨、超えたら非推奨、号数別情報がなければ要確認。知らない太さの容量を補間しません。500m巻商品を全量巻く判定にはしません。
4. **糸付きリール:** 17ワールドスピン2500には3号150mが付属するため、別売りラインの重複購入を要確認として伝えます。基本構成は糸なしCF2500です。
5. **竿とカゴ:** カゴの公称号数が竿のオモリ負荷上限より大きければ非推奨。上限ぴったりならエサを含む余裕がないため要確認。下限未満も記載範囲外として要確認。範囲内は公称のオモリ号数についてだけ推奨です。
6. **エサ込みの総負荷:** カゴ本体・エサ・仕掛けを合わせた重さが未計測なので、数値ルールが推奨でも別項目で要確認を返します。遠投はこの試作の対象外です。
7. **道糸・幹糸・ハリスの号数:** 道糸≧幹糸＞ハリスを初期構成の編集ルールにしています。この順序なら号数関係について推奨、満たさなければ要確認です。素材や結び方による実際の破断強度の保証・大小判定はしません。
8. **竿と仕掛けのハリス:** 竿の適合ハリス範囲と枝糸の号数を照合。表記外は要確認、範囲内ならこの号数比較について推奨です。サビキの枝糸に磯竿の適合ハリス表記を一律適用できるかは断定しません。基本の3号竿+ハリス1号も表記外なので要確認として公開します。
9. **針8号:** 小魚に大きすぎる場合があるため要確認。魚種名だけで針サイズが確定したと表示しません。
10. **バケツ:** DAIWAの水くみ製品はメーカーが用途を明示し8mロープを付属するので、その用途について推奨。汎用バケツは地上容器用途のみ・吊り下げ不可とする比較候補で、常に要確認です。
11. **安全装備:** 着用者の体格と施設の使用環境が未入力なので要確認。安全性を点数化したり、汎用品へ安易に代替したりしません。

## 明確な非推奨を試す

`rod-2-300` のメーカー公称オモリ上限は6号。`basket-riseway-10` は公称10号なので上限を超えます。両方を選ぶとその理由が非推奨として残り、商品は勝手に変更されません。`rod-3-300` と `basket-riseway-6` に戻すと、公称オモリ号数のルールは推奨へ再計算します。総重量や現物装着の要確認は消しません。

### 所持品の要確認が伝わる範囲

|所持品|要確認の対象カテゴリ|関連するルール|
|---|---|---|
|ロッド|ロッド、リール、カゴ、エサ、仕掛け|取り付け、公称/総負荷、適合ハリス|
|リール|リール、ロッド、ライン|取り付け、糸巻量|
|ライン|ライン、リール、仕掛け|糸巻量、号数関係|
|仕掛け|仕掛け、ライン、ロッド|号数関係、適合ハリス|
|カゴ|カゴ、ロッド、エサ|公称/総負荷|
|エサ|エサ、ロッド、カゴ|総負荷|
|バケツ|バケツのみ|容器の用途|
|安全用品|安全用品のみ|サイズ・使用環境|

無関係なカテゴリへ所持品の警告を広げません。たとえば所持バケツがあることを理由に、ラインとリールの公表仕様の比較を無効にはしません。

## 共有データの検証

URLはバージョン付きJSONをBase64URLで保持します。文字数を制限し、JSONの形、整数月、既知エリア/フィールド/魚/対応釣法、月と魚の関係、カテゴリと商品の一致、所持品/準備済みカテゴリを検証します。未知商品・異カテゴリ商品・壊れたデータは`null`として復旧UIへ渡します。外部URLやコードは共有データとして受け取らず、リンク先はカタログで管理したHTTPSホストに制限しています。

## Amazon代替品への更新（2026-10-30）

カゴをRISEWAY UPK-001 S-6号 / L-10号へ置換。判定はAmazon掲載の公称オモリ号数のみで、カゴ全体の重量ではない。基本竿の5〜10号に対して6号は範囲内、10号は上限一致で要確認、2〜6号竿に対して10号は非推奨。未計測の本体・エサ・仕掛けの総重量は常に要確認。旧カゴのg数は転用しない。

汎用バケツはRISUアクティブバケツ8Lへ変更。地上での給水容器用途のみ条件付きで比較し、水くみの吊り下げ用途は禁止。掲載されたPE/EVA等の材質だけで海水耐久性や取っ手の荷重を保証しない。出典・ASIN・確認内容は AMAZON_LINKS.md。

## 全12釣法の判定（2026-11-01）

通常の足元サビキは従来ルールを維持。他釣法とカマスは `evaluateMethodCompatibility(build)`、対象魚・釣法の候補群は `equipment.ts` で定義する。

- 必須/推奨項目は魚・釣法で変わる。推奨品の未選択は構成確認を妨げない。
- gと公称オモリ号（1号=3.75g）のみを重量として扱う。エギ号・針号・金具サイズを重量換算しない。
- セットを1商品として重複排除した確認済み重量の下限を合算する。それだけで竿の上限を超えれば非推奨。範囲内でもエサ・金具・ウキ等を含む総重量は要確認。
- リール容量はPE/ナイロン/フロロを区別。未知素材や未掲載号数は要確認。PEの号数をナイロンの容量表へ当てはめない。
- 竿のPE・エギ適合範囲を公称値と照合し、明確な範囲外を非推奨とする。力糸とルアー用リーダーは別項目。
- ウキの公称負荷とオモリ号数を照合し、明確な過負荷は非推奨。エサ入りカゴやウキ自重を含む投げ負荷とは分ける。
- 竿/リールの方式を照合。ヘチ用とスピニング用の混在を非推奨とする。取付寸法・結束・ドラグ・安全用品の体格適合は現物確認。
- セットに含む部品を別に選んでも勝手に削除しない。重複として要確認を表示し、付属品へ戻す操作を用意する。
- 別釣法に属する残存選択は現在の重量判定・付属品充足へ使用しない。

共有v3は新カテゴリと魚・釣法ごとの構成を検証する。v1/v2を読み込み、新カテゴリの未知商品・異カテゴリ・不正な構成履歴は拒否する。最大65,000文字以内。全69通りを切り替えた履歴も復元できることを検証する。
