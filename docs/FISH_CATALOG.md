# 初心者向けの30対象魚

2026-11-01の依頼で合意した30項目を `src/fish-catalog.ts` に収録。近縁種・地方名・成長段階名をまとめ、イカ類も含めます。「有名順」はユーザーと合意した掲載順で、統計に基づく順位ではありません。

- 全30項目を、月・エリア・地形を問わず選択できます。掲載が、その釣行条件での生息・回遊・釣果を保証するものではありません。
- 通称・別名・グループ内の種名で検索できます。ひらがな・カタカナ・半角を正規化し、完全一致した名前を優先します。
- 12釣法での絞り込み、合意した有名順、既存の季節データと診断回答によるおすすめ順を用意。
- 魚を選ぶ → その魚に合う釣法を選ぶ → 準備、の順で進みます。魚・釣法は既存v2形式で自動保存・共有URLから復元します。

## 季節データ・購入商品の範囲

全国の魚の選択と、検証済みの地域別季節データを区別します。既存の `seasonality` は東京湾・堤防のアジ、イワシ、小サバのみです。未調査の全国的な釣期を仮の月データで埋めません。

`hasProductGuide` は、その季節データに合う3魚種・足元のサビキだけに購入商品の提案を許可します。ほかの魚・釣法では、準備品と基本手順のガイドを表示します。既存のサビキ仕掛けやコマセをルアー・エギングなどに推奨しません。商品選択・購入・完成画面への直接URLも、この条件で保護します。

旧v1の季節判定・商品ID移行を維持します。v2では、季節データのない魚や条件でも魚・釣法の選択を復元できます。未知の魚・釣法、魚に対応しない釣法は引き続き拒否します。
