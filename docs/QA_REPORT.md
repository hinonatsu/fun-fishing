## 検証の限界

- ブラウザ操作は自動テストおよび開発者による画面レビュー。実在ユーザーへのユーザビリティ調査ではない。
- Firefox、WebKit、実機スマートフォンは未検証。
- 購入先の在庫・価格・購入手続きは検証対象外。
- Amazon個別商品リンクは型番・ASINの対応を確認できず未実装。代わりに実在の公式販売元・釣具店の個別リンクを使う。14商品のうち販売ページ本文まで確認できたのはDAISOの3商品で、他は検索掲載とJAN等の照合にとどまる。詳細は`DATA_SOURCES.md`。
- 提案データは同梱しており、遠隔APIの障害を扱う機能はない。ライブ価格・在庫・釣果の取得は実装しない。
- WCAG 2.2 AAの完全準拠は宣言しない。自動検査とキーボード確認で検出可能な範囲を確認する。
